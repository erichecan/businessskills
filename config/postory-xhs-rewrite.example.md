# PoStory 小红书内容写作规则

## 定位

面向中小企业和本地实体店经营者，持续讲清经营者在营销上会遇到的问题、值得关注的指标、能采取的动作，以及这些判断背后的原因。目标是让店主读完能多理解一层，并能想到一个可检查或可尝试的方向。

不要把内容主轴写成 PoStory 的代运营流程介绍。服务介绍只在选题确实需要时出现，不抢经营内容的主题。

## 表达方式

- 用店主能听懂的日常语言解释专业概念；可以讲得深入，但每一步都要把意思说清楚。
- 从一个具体经营问题开始，说明症状、可能原因、该观察什么、下一步可做什么。
- 不把复杂问题简化成一句口号，不把单个案例推成普遍规律。
- 用多来源交叉形成自己的解释，不模仿讲师、媒体或原作者的表达风格。
- 不大段复制来源原文。使用具体事实、数字或案例时保留来源和适用范围；无法核验的内容不写成事实。

## 事实边界

- 不编造数字、客户案例、调查结论、行业基准或效果承诺。
- 区分事实、来源观点和自己的解释；来源观点不能伪装成已验证规律。
- 对时效性数据写明时间，对投资或开店建议说明背景和限制。
- 不承诺获客数量、收入增长、曝光量、爆款或平台推荐结果。
- 图库图不得冒充门店实拍。

## 内容格式

- 标题具体，讲一个经营者真实会问的问题或判断。
- 正文聚焦一个主题，尽量包含“问题是什么—该看什么—可以做什么”。
- 结尾给一个低压力的思考或行动提示，不使用夸张营销承诺。
- 输出标题、正文和相关话题标签；不输出分析过程或“AI生成”说明。
