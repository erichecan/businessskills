# 提炼痛点

从任意文本内容中提炼职场表达痛点，写入本地痛点库（http://localhost:8000）。

## 使用方式

```
/提炼痛点 <文本内容>
```

或不带参数，直接运行，Claude 会提示你粘贴内容。

---

## 执行步骤

### 第一步：获取待分析内容

如果 `$ARGUMENTS` 不为空，使用 `$ARGUMENTS` 作为待分析内容。

如果 `$ARGUMENTS` 为空，告知用户：
```
请把要分析的文本内容粘贴进来（小红书评论、私信、用户访谈记录等均可）。
```
然后等待用户输入，将用户下一条消息作为待分析内容。

---

### 第二步：检查服务状态

```bash
curl -s http://localhost:8000/api/stats 2>/dev/null | python3 -c "import sys,json; d=json.load(sys.stdin); print(f'痛点库在线，共 {d[\"total\"]} 条')" 2>/dev/null || echo "服务未启动"
```

如果服务未启动，提示用户：
```
⚠ 痛点库服务未启动，请先在终端运行：
cd xhs/职场表达力/工具/痛点库
ANTHROPIC_API_KEY=你的key python3 app.py
```
然后停止执行。

---

### 第三步：调用 AI 提炼接口

将待分析内容发送给提炼接口：

```bash
curl -s -X POST http://localhost:8000/api/extract \
  -H "Content-Type: application/json" \
  -d '{"content": "<待分析内容（JSON转义）>"}'
```

**重要**：构造 JSON 时必须正确转义内容中的双引号、换行符等特殊字符。使用 Python 来安全构造请求体：

```bash
python3 -c "
import json, urllib.request
content = '''<待分析内容>'''
req = urllib.request.Request(
    'http://localhost:8000/api/extract',
    data=json.dumps({'content': content}).encode(),
    headers={'Content-Type': 'application/json'},
    method='POST'
)
with urllib.request.urlopen(req) as r:
    print(r.read().decode())
"
```

---

### 第四步：展示提炼结果

解析响应，用清晰的格式展示每条痛点：

```
✦ 提炼结果（共 N 条）

① [场景] [严重度]
   触发时刻：……
   内心独白：……
   实际后果：……

② ……
```

如果响应包含 `error` 字段，显示错误信息并停止。

---

### 第五步：询问是否写入库

```
以上 N 条痛点已提炼完成。

写入痛点库？
  a. 全部写入
  b. 选择写入（告诉我序号，如：1 3 5）
  c. 不写入，仅查看
```

根据用户回复执行：

**全部写入（a）**：

```bash
python3 -c "
import json, urllib.request
items = <提炼结果列表>
for it in items:
    it['source'] = 'extracted'
    req = urllib.request.Request(
        'http://localhost:8000/api/pain-points',
        data=json.dumps(it).encode(),
        headers={'Content-Type': 'application/json'},
        method='POST'
    )
    with urllib.request.urlopen(req) as r:
        d = json.loads(r.read())
        print(f'已写入 #{d[\"id\"]}：{d[\"trigger_moment\"][:20]}…')
"
```

**选择写入（b）**：只写入用户指定序号的条目，循环逐条 POST。

**不写入（c）**：回复「好的，已取消写入。可以在浏览器 http://localhost:8000 手动操作。」

---

### 第六步：完成汇报

写入成功后：

```
✅ 已写入 N 条痛点到库中
   打开 http://localhost:8000 查看全部痛点
```

同时展示更新后的统计：

```bash
curl -s http://localhost:8000/api/stats | python3 -c "
import sys, json
d = json.load(sys.stdin)
print(f'当前库共 {d[\"total\"]} 条痛点')
for k,v in d['by_scenario'].items():
    print(f'  {k}: {v}')
"
```

---

## 适用场景

- 小红书评论区批量提炼读者痛点
- 私信截图转文字后批量提炼
- 用户访谈记录整理
- 课程学员反馈归纳
- 任何包含职场表达困境的文本
