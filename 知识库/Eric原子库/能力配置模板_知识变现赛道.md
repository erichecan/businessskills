# 能力配置模板：知识变现赛道
**版本：** v1.0 草稿
**更新：** 2026-04-26
**用途：** 客户选定知识变现方向后，逐步填写，交付一页纸配置报告

---

## 第一步：知识盘点

> 目标：找到客户真正可以变现的知识领域，排除「感兴趣但没积累」的误判。

**诊断问题：**

1. 你做过什么工作？哪个领域有 5 年以上的实操经验？
2. 你身边有哪类人，经常来问你同一类问题？（这就是你的领域）
3. 你帮别人解决过什么具体问题，对方觉得很有价值？
4. 你能用 3 句话，向一个外行人解释这个领域里 80% 的人不知道的事？

**输出：**
```
领域定义：_______________________
核心知识点：_______________________（3-5 个，用动词开头）
目标买家：_______________________（谁会因为没有这个知识而吃亏？）
```

**常见陷阱：**
- 「我什么都懂一点」→ 不是领域，是信息消费
- 「我对 XX 很感兴趣」→ 兴趣 ≠ 积累，问：你帮别人解决过这个问题吗？

## 第二步：知识产品化

> 目标：把知识变成有人愿意付钱的产品，而不是知识笔记或总结。

**核心原则：没有人买「知识」，人们买「用知识解决某个具体问题的结果」。**

**诊断问题：**

1. 你的目标买家现在有什么具体的痛苦或恐惧？（不是「想学XX」，是「因为不会XX导致了什么后果」）
2. 买了你的产品之后，他们的生活/工作会有什么具体变化？（用数字或场景描述）
3. 他们为什么现在还没有解决这个问题？（太贵？不知道去哪学？没时间？不知道方法？）

**产品定义公式：**
```
帮 [目标买家] 在 [时间范围] 内 实现 [具体结果]，
即使他们 [目标买家最常见的顾虑/障碍]。

示例：
❌ 「理财知识课」（知识笔记）
✅ 「帮工薪族在 3 个月内把月储蓄率从 0 提升到 20%，
     即使你现在一分钱都存不下来」
```

**产品命名检验（3 个问题）：**
- [ ] 听到名字，买家知道自己买完会得到什么结果吗？
- [ ] 名字里有没有他们害怕的词或渴望的词？
- [ ] 说出来 10 秒内，目标买家会说「这说的是我」吗？

**输出：**
```
产品名称：_______________________
产品定义（一句话）：_______________________
产品形式：□ 1v1 咨询  □ 小班课  □ 录播课  □ 图文手册  □ 其他
定价范围：_______________________（先定，后验证）
```

## 第三步：讲好

> 目标：能在任意场合把产品讲清楚，让人听完第一反应是「我需要这个」。

**讲好的结构（三段式）：**

```
① 戳痛点（10秒）
   「你有没有遇到过这种情况：_______________」

② 说后果（10秒）
   「大多数人的做法是___，结果是___」

③ 给希望（10秒）
   「我有一套方法，可以帮你在___时间内___。我已经帮___个人做到了这件事」
```

**内容呈现原则：**
- 案例 > 理论：每一个观点，配一个真实故事
- 可验证 > 可信赖：给买家一个可以立刻尝试的小动作，让他在买之前就感受到价值
- 具体 > 正确：「3 个步骤」比「系统方法论」更能触发购买

**能力建设（缺什么补什么）：**

| 能力 | 现状 | 需要 | 去哪学 |
|------|------|------|--------|
| 结构化表达 | | | |
| 案例积累 | | | |
| 内容产出（视频/图文） | | | |

## 第四步：卖好

> 目标：让知识产品稳定成交，而不是靠运气。

**成交链路（从陌生人到付钱的路径）：**

```
内容（让陌生人停下来）
    ↓
信任（让人觉得你懂他的问题）
    ↓
触发（让人觉得现在必须行动）
    ↓
成交（让付钱这个动作变得简单）
```

**诊断：你目前哪一步断了？**

- [ ] 内容层：没有人看到你的内容（触达问题）
- [ ] 信任层：看到了但不相信你（可信度问题）
- [ ] 触发层：相信你但没有行动（紧迫感问题）
- [ ] 成交层：想买但付钱流程太复杂（摩擦力问题）

**定价策略（知识变现常见坑）：**
- 定价过低 = 买家不认真，完课率低，口碑差
- 定价标准：你帮买家解决这个问题，他能省多少钱 / 多赚多少钱 → 取 10-30%
- 第一个价格不是最终价格，是测试价格

**能力建设：**

| 能力 | 现状 | 需要 | 去哪学 |
|------|------|------|--------|
| 内容引流 | | | |
| 私信成交话术 | | | |
| 直播/分享成交 | | | |

## 第五步：交付好

> 目标：让买家完成课程并拿到结果，然后主动推荐别人来买。

**交付 = 结果，不是内容。**

买家不是买了「10 讲视频」，他买的是「3 个月后月存款从 0 到 20%」。如果他买完没有拿到结果，退款/差评/没有复购是必然。

**标准交付设计：**

```
① 开始仪式（第一天）
   让买家明确：买了这个我能得到什么结果，我需要做什么配合

② 里程碑设计（过程中）
   每 1-2 周，买家能完成一个小目标，感受到进展

③ 作业/检验机制
   有反馈，有纠正，不只是看视频

④ 结业仪式（结束时）
   帮买家总结他拿到了什么，引导他分享/推荐
```

**复购和口碑设计：**
- 结业时问一个问题：「你现在解决了 XX 问题，下一个想解决的是什么？」→ 引向下一个产品
- 设计一个「带朋友来」的机制（推荐返佣 / 双人拼团 / 老学员价格）
