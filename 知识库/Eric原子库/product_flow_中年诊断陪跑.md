# 中年转型诊断 × 能力配置陪跑
## 产品第一版流程（草稿）
**创建日期：** 2026-04-26
**来源：** 与 eric-diagnosis 的问诊对话提炼

---

## 产品定位

帮 40 岁中年人找到下一个 10 年能奋斗且赚钱的事，并完成能力配置。

**产品类型：** 流程型（卖过程/方法论），不是答案型（卖结论）。

**关键区别：**
- 答案型 = 「我告诉你去哪里捡钱」→ 需要自己已经成功，算命先生悖论成立
- 流程型 = 「我带你走一套找方向的过程」→ 不需要自己已有结论，方法论是交付物

---

## 目标用户

- 40 岁左右，面临中年危机
- 有收入焦虑（降薪/失业/看不到未来）
- 想找到一个「下一个 10 年」的方向
- 不知道从哪里开始，或者有方向但不确定能不能做

---

## 获客路径

```
小红书内容（中年焦虑/方向迷失话题）
         ↓
钩子触发（看到内容感同身受）
         ↓
私信/评论联系 → 进入诊断流程
```

**内容策略：** Eric 自己摸索过程的记录 + 方法论输出。「一个 40 岁的人正在找自己的下一个方向，边找边记录，带着读者一起找」本身就是内容。

---

## 核心服务流程

### Phase 0：钩子触发（内容层）

内容聚焦话题：
- 中年危机/方向迷失
- 「十个方向都想做，一个都没做」
- 收入焦虑、被替代恐惧
- 如何从 0 开始找下一个方向

目标：让目标用户主动找你。

---

### Phase 1：问题采集（首次接触）

问客户三个问题：

1. **你现在遇到了什么具体问题？**（收入/职场/方向/家庭压力）
2. **你羡慕哪个朋友赚到了钱？他是怎么赚的？**
3. **你自己看好哪个方向能赚钱？为什么？**

根据回答分流：
- **有方向** → Phase 2A（方向诊断）
- **没方向 / 只想赚钱** → Phase 2B（找方向）

---

### Phase 2A：方向诊断（客户有候选方向）

用五重过滤法逐项判断：

| 筛子 | 问题 |
|------|------|
| 1. 赚钱 | 这个方向有人赚钱吗？利润是你现在的 10 倍吗？ |
| 2. 看懂 | 你能说清楚他怎么获客、转化、交付、复购吗？ |
| 3. 能仿 | 你有能力在合理时间内执行他的模式吗？ |
| 4. 排除自我 | 不讨论兴趣偏好，只讨论能不能做 |
| 5. 不讨论本质 | 不讨论行业前景，只讨论利润 |

**输出：** 能做 / 现在不能做（原因） + 如果不能做，给 3 个可以做的调整方向

---

### Phase 2B：找方向（客户没方向）

用问诊消解漏斗：

**实战识别方式：不需要判断类型，只听三种信号词**

| 信号词 | 背后问题 | 应对 |
|--------|---------|------|
| "确定 / 成熟 / 准备好 / 有把握" | 语言陷阱——词没有定义 | "你说的确定，什么算确定了？" |
| "等我…再… / 要先…才能…" | 假设错误——自己发明的前提条件 | "为什么一定要先做这件事？" |
| "所以我没办法 / 所以不行" | 逻辑错误——结论跳了 | "为什么有这个困难就不能做了？" |

听到这三类词就停下来，把那个词还给他。不需要提前判断是哪个类型。

**Layer 1：语言陷阱检测**
- 「找不到确定的方向」→ 问：什么叫确定？签了合同算？有人付钱算？
- 「十个方向都可以」→ 问：都有什么困难？哪个困难是你能解决的？
- 「想卖有价值的东西」→ 问：价值由谁定义？

**Layer 2：假设错误检测**
- 「方向是找到的」→ 方向是测试出来的，不是想出来的
- 「要先找到再开始」→ 边走边找才是路径

**Layer 3：逻辑错误检测**
- 「十个方向都可以」是资源，不是问题
- 区分：不知道方向 vs 不敢执行 vs 不知道第一步

**Layer 4：触发行动（最难，必须在对话结束前完成）**

> ⚠️ 不能留作业——留作业的完成率接近零。必须在对话还在的时候触发。

**第一步：找到那个人**（不是去联系，只是想到）

> "你脑子里现在有没有浮现出一个具体的人——不是泛泛的'40岁的人'，是一个你认识的、名字脸都有的人，他现在正在经历你说的这个问题？"

- 有 → 进第二步
- 没有 → 方向还不够具体，回到 Layer 1-3 继续

**第二步：把动作缩到一条消息**

> "你不需要卖给他。只需要发一条消息：'我最近在想一件事，跟你有点关系，有没有时间聊 15 分钟？'就这一句。你能今天发吗？"

关键：把「去测试」变成「发一条消息」，把「验证商业模式」变成「聊 15 分钟」。让他在对话里把消息写出来，甚至发出去。

**输出：** 一个可以立刻开始测试的方向 + 今天发出的那条消息

---

### Phase 3：能力配置

确定方向后，帮客户配置执行能力：

**步骤：**
1. 列出做这个方向的核心能力清单（3-5 项）
2. 逐项判断客户现在有没有
3. 缺的部分：去哪学 / 怎么学 / 多长时间
4. 可对接配套课程（未来扩展）

**输出：**
- 能力现状评估
- 缺口清单
- 学习路径推荐

---

### Phase 4：行动交付

**标准交付物：**
- 方向诊断结论（一句话：你能做/你现在不能做，原因）
- 能力配置清单（现有 vs 需要 vs 如何获取）
- 90 天第一步行动计划（具体到周）

**可选扩展：**
- 持续陪跑（定期复盘，障碍清除，1-3 个月）
- 配套学习资源 / 课程

## 核心产品信念

1. **帮人走流程，不是给人答案** — 方向是客户测试出来的，不是你告诉他的
2. **自己摸索 = 内容，不是资格缺失** — 同行者比导师更可信
3. **能力配置是稀缺交付** — 大多数「方向」建议停在「你应该做 XX」，没有配置到「你用什么能力做 XX」
