# 中年转型诊断 · 问题卡　　　　　　　　　　　　　　　　　v1.0 / 2026-04-26

---

## PHASE 1　问题采集　▶ 目标：分流

1. 你现在最大的压力是什么？收入 / 职场 / 方向 / 其他？
2. 你身边有没有哪个朋友最近赚到了钱——他是怎么赚的？
3. 你自己有没有觉得「这个我也能做」的方向？说一个就够。

```
第 3 题有答案 ──→ PHASE 2A
第 3 题没答案 ──→ PHASE 2B
```

> **跑题信号**：客户开始讲家庭、抱怨公司、说行业前景
> → 拉回：「这个我理解，我想先搞清楚你现在最想解决的一件事是什么。」

---

## PHASE 2A　方向诊断　▶ 目标：判断能不能做　（五重过滤，顺序不跳）

| # | 筛子 | 问题 |
|---|------|------|
| 1 | 赚钱 | 你认识的人里，有没有在这个方向真的赚到钱的？他一个月大概多少？ |
| 2 | 看懂 | 他怎么找到客户？怎么收费？怎么交付？你能说清楚吗？ |
| 3 | 能仿 | 他的模式，你现在能不能执行？缺什么？ |
| 4 | 排除偏好 | 你是因为喜欢，还是因为觉得能赚到钱？ |
| 5 | 只看利润 | 不管行业好不好，这个方向做下去，你能比现在多赚多少？ |

**输出**：能做 / 现在不能做（原因）+ 1-2 个可调整方向

---

## PHASE 2B　找方向　▶ 目标：找到一个今天能测试的方向

**先听信号词，再应对——不需要判断是哪种类型**

| 听到这类词 | 应对 |
|-----------|------|
| 确定 / 成熟 / 准备好 / 有把握 | 「你说的确定，什么算确定了？」 |
| 等我…再… / 要先…才能… | 「为什么一定要先做这件事？」 |
| 所以我没办法 / 所以不行 | 「为什么有这个困难就不能做了？」 |

**四层推进（每层通过再往下）**

```
Layer 1  语言陷阱  →  把模糊词还给他，让他自己定义
Layer 2  假设错误  →  「谁说这件事必须先做？」
Layer 3  逻辑错误  →  「十个方向都可以」是资源，不是问题
Layer 4  触发行动  →  见下方【行动触发】
```

---

## PHASE 3　能力配置　▶ 目标：一张缺口清单

1. 做这个方向，你觉得最核心的能力是什么？（让客户先说）
2. 这几项里，你现在哪个有，哪个没有？
3. 没有的，你知道去哪学吗？大概多久能补上？

**输出**：填满能力配置表（现有 / 缺口 / 学习路径 / 时间）

---

## ⚡ 行动触发　▶ 对话结束前必须完成，不能留作业

**第一步：找到那个人**

> 「你脑子里现在有没有浮现出一个具体的人——不是泛泛的'40岁的人'，
> 是一个你认识的、名字脸都有的人，他正在经历你说的这个问题？」

- 有 → 进第二步
- 没有 → 方向还不够具体，回 Phase 2B 继续

**第二步：缩到一条消息**

> 「你不需要卖给他。只发一条消息：
> '我最近在想一件事，跟你有点关系，有没有时间聊 15 分钟？'
> 就这一句。你能今天发吗？」

让他在对话里把消息写出来，甚至直接发出去。

---

*守住一个阵地：让诊断对话稳定、可复制、客户体验一致。打呆仗的人，赢的是时间。*
