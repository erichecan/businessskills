# PoStory 小红书封面与图卡

把每篇笔记设计成完整竖版图卡。画布为 1242×1660 px；为手机阅读保留安全边距、清楚的字体层级和可读字号。使用 PoStory 玫红 `#EC008C`、橙色 `#FF7A00`，搭配暖白、深墨色和少量浅色分区。

## 固定识别与可变内容

- 固定 PoStory 引导角色的身份特征：肩长深色头发与刘海、藏蓝外套、白上衣、米色长裤、白鞋、黄色夹板、黑色手绘线条和温暖的平涂色彩。
- 从 `assets/postory-xhs/mascot/poses/` 选择已审核的透明 PNG 姿态；使用 `mascot/poses/index.json` 了解姿态含义。不要在每次出稿时重新生成角色。
- 固定角色身份，不固定动作、位置或是否出现。每篇最多在封面和 2–3 张内页出现角色；不要连续页面重复同一个姿态。页面没有角色时，用内容图解承担视觉重点。
- 需要新增姿态或场景插画时，先制作并审核后加入素材库。CLI 渲染只读取固定素材和笔记数据，不调用图像生成。

## 先规划页面，再选择图形

为每页写清“本页只传递的一件事”和“读者看完能做什么”，再选匹配的视觉语法。每页都要有视觉承载物，但不强迫每页都有角色或独立场景插画。

| 视觉语法 | 适合的内容 |
|---|---|
| 场景 / 故事板 | 顾客犹豫、服务现场、经营问题的前后变化 |
| 顾客旅程 | 看到内容、咨询、预约、到店、回访、复购 |
| 流程 / 步骤 | 服务交付、营销动作、售后跟进 |
| 分组 / 矩阵 | 新客与熟客、不同服务对象、问题分类 |
| 对比 | 常见做法与替代做法、不同沟通重点 |
| 漏斗 | 从触达、兴趣、咨询到预约等逐步筛选过程 |
| 对话 / 话术 | 预约咨询、报价、回访、异议回应 |
| 检查清单 | 店主可以立即执行的核对动作 |

选择图形时依据本页正文，不要整篇重复同一种卡片结构，也不要放与信息无关的装饰图。数据图只展示素材中有依据的数字，并写清日期、来源和口径；没有可靠数字时，改用流程、分类或比较图。

## 页面节奏

- **封面**：用店主熟悉的具体场景、经营误区或结果张力吸引阅读。品牌标签、主标题、副标题和图形重点保持稳定；角色可以出现，也可以让场景图解独立承担主视觉。
- **问题页**：写清具体经营处境，可选择场景、故事板或顾客对话。角色适合倾听、思考或观察，不要默认使用指向姿态。
- **解释页**：把原因或对象差异讲清楚，优先用分组、矩阵或对比图。角色仅在帮助解释时出现。
- **行动页**：把方法拆成旅程、步骤、话术或检查清单。必要时使用讲解、看图表、提醒或指向下方的姿态。
- **结尾页**：收束成读者现在能完成的一项动作；CTA 可省略，不强迫互动。

## 文案与版式

- 每页一个主标题和有限正文；长段落拆成短句、对话或步骤，不通过缩小字号来解决拥挤。
- 封面标题使用店主自然会说的话，点出行业场景和具体问题；封面标题与发布标题互补，不夸大效果。
- 确保图卡层级、页码、品牌识别和留白一致，图形结构可以按内容变化。
- 不用无来源的图库照片冒充本地商家实拍，不编造顾客、数据、价格、承诺或经营成效。
- 输出 `note.json`、发布正文和逐页 PNG；检查每页文字溢出、手机可读性、图形含义、角色姿态选择、来源标注和页码。
