## 一、为什么这么改

现状是两套互不相通的世界：

- **采集层（定时任务，强项保留）**：`xiaohongshu-career-interview-digest` 每 6 小时跑，自进化关键词池 + 去重 + 学结构，产出 `记忆库.csv / 关键词池.csv / 高热结构库.md / 当日xlsx`。`xiaohongshu-content-repurpose` 每天 8:30 把素材加工成 `选题大纲.docx + 选题库.csv`。**这套很能干，但终点是文件，勾选后没有下游。**
- **app 内容工坊（能力强但断粮）**：`HotTopic → Topic → Content`，有诊断 / 代写 / AI检查 / 标题四道工序（调 Claude + eric-* skill），但 `/api/scrape` 只抓微信公众号 RSSHub，小红书素材进不来。

**重构思路**：采集层继续做它最擅长的"抓 + 学"，但产物**增量入库到 app**，让选题立项、成稿、AI检查、标题全部回到工坊里跑，形成一条线。

> 顺带修正一个之前的判断：记忆库现已累积 **292 行**（不是停在 84），说明采集任务其实在持续增量入库，并非空转。

## 三、数据模型映射

| 素材库文件 | 字段 | → app 模型 | 落点 |
|---|---|---|---|
| `职场面试_记忆库.csv` | 标题 | `HotTopic.title` | 直接 |
| | 链接 | `HotTopic.url` | 直接（注：当前是搜索页URL，待采集层改为笔记详情页） |
| | 热度（"37万"） | `HotTopic.engagementScore` | **数值化**（37万→370000） |
| | 关键词/来源/首次收录/热度原始 | `HotTopic.rawData`(JSON) | 保留可追溯 |
| | platform | `HotTopic.platform="xiaohongshu"` | 固定 |
| `选题库.csv` | 选题名 | `Topic.title` | 直接 |
| | 归属板块 | `Topic.angle` | "板块：xxx（来自选题库 日期）" |
| | 状态（待勾选/已勾选） | `Topic.status` | 待勾选→draft，已勾选→approved |
| `知识框架.md` | 全文 | 选题立项 / 成稿的 system prompt | 当作"脑"注入（同 eric-* skill 用法） |
| `高热结构库.md` | 钩子/骨架 | 标题与结构参考 | 注入提示词 |
| 当日 `xlsx` 内容表 | 核心要点/标题套路/结构类型 | `HotTopic.rawData` 富化 | 下一步（需加 SheetJS） |

去重键：`url` 优先、**归一化标题**（去 emoji/标点/空白）兜底。实测记忆库里有 20 条标题级重复会被这层收掉。

## 四、本次已落地（代码）

均在 `app/`，**无需 schema 迁移**（复用现有 `HotTopic` / `Topic` 字段），低风险可直接 `npm run dev` 试。

1. **`app/src/lib/sucai.ts`（新增）**：素材库读取助手。
   - `sucaiDir()`：默认 `../xhs/素材库`，可用环境变量 `SUCAI_DIR` 覆盖。
   - `parseHeat()`：热度字符串→数值（万/w/带逗号/—）。
   - `parseCsv()`：零依赖 CSV 解析（支持引号包裹、字段内逗号）。
   - `normalizeTitle()`：归一化标题做去重兜底键。
   - `readMemoryNotes()` / `readTopicLibrary()`：读两个 CSV 成结构化对象。
2. **`app/src/app/api/scrape/route.ts`（扩展）**：`POST {platform:"xiaohongshu"}` → 读记忆库.csv，按 url+归一化标题去重，增量写 `HotTopic`（含热度数值化、rawData 留痕）。微信路径不动。
3. **`app/src/app/api/import/topics/route.ts`（新增）**：`POST` → 读选题库.csv，去重后写 `Topic`，状态映射，并尝试按标题模糊关联一条小红书 `HotTopic` 作来源。

**怎么用（app 跑起来后）：**
```bash
# 小红书素材入库
curl -X POST localhost:3000/api/scrape -H 'Content-Type: application/json' -d '{"platform":"xiaohongshu"}'
# 选题入库（接通勾选→工坊）
curl -X POST localhost:3000/api/import/topics
```
返回形如 `{"message":"小红书素材入库完成，新增 N 条，跳过重复 M 条", ...}`。
