## 第一部分：面向未来的 IP 定位（一句话到护城河）

### 定位演化（一个月走过的路）
泛"中年转型"十个方向 → Week1-8 训练营 + 81 条方向库 → 发现方向全塌缩成"知识付费" → **收窄落地到"职场表达力 / 面试表达"**。这是一条"从想清楚到敢出货"的路，核心张力始终是：**用"建框架"代替"真出内容"**——而这恰恰是你自己的诊断框架要破解的中年卡点。所以定位的终点不是再想一版，而是持续出货。

### 定位定稿（v3）
- **一句话**：前腾讯资深中层，教你把"能力"翻译成对方愿意买单的语言。
- **战略架构**：能力为体，场景为用。"职场表达力"是底层能力品牌，**面试是第一个、最痛的入口场景**，不是全部。四场景上线序：面试 → 谈薪 → 汇报 → 向上管理。
- **差异主张**：市场上讲"面试技巧"（太通用）、"改简历"（只改纸面）的多，几乎没人从**"现场表达"**切入——把你真实做过的事当场讲出亮点、扛住追问。这是技巧和模板都解决不了的命门。
- **三层护城河**：① 前腾讯资深中层（双向管理 / 面试官视角）② 双向翻译能力（话术抄得走，判断力抄不走）③ 结果可衡量（offer 截图、改前改后对比）。
- **人设基调**：目击者视角、卖共鸣不卖仰望——"我也在路上，我们一起跑"，而非高高在上的老师。

### 目标人群三层
引流主力（毕业~3 年，"进不了场"）/ 训练营主力（3-5 年，"升不上去"）/ 高端一对一（5 年以上，只做定制）。

### 商业模式骨架
免费钩子品 → 面试训练营（首购）→ 谈薪训练营（连购）→ 汇报训练营（利润）→ 5 年以上一对一（高客单）。私域=有偿共创。**定价仍是最大未决项（TBD），建议尽快用前 3 个免费学员跑通定价。**

> 战略提醒（来自你自己的文档）：①"价值只能被交易验证"——别再用迭代代替出货；② 博商只抄逻辑（漏斗/单粉价值/赛马/大众语言），不抄人海与资本；③ 2026 教培监管趋严 → 单账号做深、3-5 个号、前期纯自然流不投流。

## 第四部分：优化方案（按优先级，重点在"自动执行"）

### P0 · 本周就做（高杠杆、低成本）
1. **填好知识框架**（已完成）。后续每月回看一次即可。
2. **采集去重键升级**：以 noteId / 笔记详情页 URL 为主键，标题做归一化（去 emoji / 空白 / 标点）兜底。落详情页链接，能追溯能复看。
3. **热度数值化**：新增 `likes_num` 数字列（万→10000，"—"→空），保留原始展示列。命中率 / 平均热度从此自动算，不再人工估"中/高"。
4. **加运行日志**：每次采集写 `运行日志.csv`（时间 / 用了哪些词 / 新增数 / 失败原因）。**连续 N 天新增=0 自动告警**，根治"静默空转"。

### P1 · 自动执行可靠性（失败 / 降级 / 幂等 / 编排）
5. **失败处理**：小红书需登录态、易触发风控，是最大风险点。失败时**不覆盖上次产物** + 写日志 +（可选）通知；网页与小红书两路解耦，一路挂不拖累另一路。
6. **降级**：补"小红书抓取失败 → 仅出网页增量并在产物标注"的降级路径（对齐加工任务已有的"框架未填→通用框架+顶部警告"范例）。
7. **幂等**：当前按"追加"写文件，任务重入会重复。写入前按 `(日期, noteId/归一化标题)` 去重；关键词池 / 选题库按日期幂等覆盖当天行。
8. **依赖编排**：加工任务开跑前先校验"近 N 天是否有新素材"，无则**跳过并通知**，而不是空转产出和昨天雷同的 5 个选题。
9. **采集频次复议**：每 6 小时对小红书"最新"未必有足够新增，反增空转与风控概率。建议降到每天 1-2 次，或保留高频但加"无新增即静默退出"。

### P2 · 选题质量
10. **选题去重**：加工时读历史 `选题库.csv`，已做过的角度跳过；素材不足时**少于 5 个并说明原因**，不硬凑。
11. **跨时窗取材**：加工改为消费"近 N 天未被选题过的高热素材"，让 6/12/18 点的增量也能进入选题池。
12. **打分透明化**：把知识框架里的"痛点×搜索量×购买意愿"三维打分写进每个选题大纲，低于阈值的不出。

### P3 · 闭环（把半自动升级为自学习）—— 最关键的两个补口
13. **补"勾选→成稿"第二段**：当前选题库状态停在"待勾选"。两条路选一：(a) 勾选结果导入 app 的 Topic 表，走内容工坊既有的诊断/代写/标题/AI检查；(b) 文件侧加一个"读取已勾选选题→扩写成稿"的第二段任务。
14. **补"发布→复盘回流"**：建 `发布复盘.csv`（选题 → 自己发布后的真实赞藏评 → 关键词/结构标签）。**让关键词池升降级和高热结构库部分基于你自己的数据**，而不只是别人的爆款。这是把系统从"抄爆款"升级为"懂我账号"的唯一通道。

### 待你确认的两处
- **文档与调度脱节**：采集设计文档写"每天09:00"，实际 cron 是 0/6/12/18。要么更新文档，要么改调度——需你定。
- **app 与文件系统未打通**：app 的 /api/scrape 只抓微信公众号 RSSHub，和小红书素材库是两套独立世界。是否要把两者合并为一个数据源，是个架构决策。
