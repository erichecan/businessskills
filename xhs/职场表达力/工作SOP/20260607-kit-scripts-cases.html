私信首响话术
对应 P-M1 承接 · Day 6-7 接私信用
4 条原则:① 24h 内首响 ② 先给价值(发模板/答一句),再了解情况 ③ 顺手收集打标(岗位/经验/目标公司/卡点)④ 不一上来推销——求职用户理性,油腻会跑。
场景 A来「领模板」的(最高频)
你好呀~模板发你 👉【链接/文件】，按里面的结构改,简历会清爽很多。 我之前在腾讯做产品 + 当面试官,面过几百号候选人。 方便的话告诉我两句,我能给你更对路的建议: ① 你现在是应届还是社招?② 目标什么岗位 / 公司?③ 现在最卡在简历、笔试还是面试哪一步?
要点:先发模板(兑现钩子)→ 亮身份(信任)→ 3 个问题自然打标,不索取过度。
场景 B直接问具体问题(如"空窗一年怎么解释")
这个问题挺典型的,很多人就栽在这。 先给你一个方向:别解释"为什么空窗",要讲"这段时间你为目标做了什么"——面试官怕的是你停摆,不是你休息。 不过具体怎么说得看你情况:你空窗这一年大概在忙什么?目标是回原来的岗位还是转方向?说说,我帮你想怎么讲最稳。
要点:先给一句真干货(证明你专业)→ 再问情况(顺势打标)→ 给"我帮你想"的承接钩子。
场景 C问"有没有辅导 / 怎么收费"(高意向)
有的~我这边主要是 1v1 帮你把简历和面试现场表达打磨到能拿 offer。 不过为了不浪费你钱,我一般先看看匹不匹配:你目标岗位 / 经验几年 / 最近面试卡在哪? 你发我一下,我先免费帮你诊断一个最大的问题。你觉得有用,我们再聊要不要深入 🙂
要点:不报价硬卖 → 先「免费诊断一个问题」筛匹配 + 给价值(博商:用低门槛钩子筛意向)→ 把决定权交回对方。

每次聊完,顺手打标(存进表格 / 备注)

身份:应届 / 社招 / 转行目标岗位经验年限目标公司卡点:简历 / 笔试 / 面试 / 谈薪意向:观望 / 准付费

案例库填空模板
内容母体的原料(P-C2)+ 信任锤(P-M4)· 往里填就成案例库
为什么先攒案例:它是你整条产线的原料——每个真实案例能拆出好几条选题,offer 截图/改前改后是求职赛道最强信任锤。没案例,内容就只能讲通用道理,跟红海没区别。先填 3-5 个,够第一个月用。
示范3 年经验 PM · 讲项目讲不清贡献
学员标签(脱敏)
3 年经验产品经理 / 二本 / 想跳大厂
初始问题
简历漂亮("负责会员功能,DAU 提升 30%"),但一到面试讲项目就垮
关键场景(选题来源)
面试官追问"这 30% 里你的贡献是什么、怎么归因",当场卡壳
他原来怎么做(错误示范=送命话素材)
翻来覆去"这是我负责的",只会复述简历数字
你怎么改的(方法=解码器素材)
教他用"背景冲突→我的判断→取舍→结果反思"讲,重点讲"为什么这么定、舍了什么"
结果(信任锤)
2 周后拿到 2 个中厂 offer,薪资涨 25%(offer 截图已存)
能拆出的内容
① "具体讲讲"怎么答 ② 被追问贡献怎么答 ③ 工具人 vs 主导者讲法 ④ 讲述结构 3 步法
