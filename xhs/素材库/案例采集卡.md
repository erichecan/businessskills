# 案例采集卡（原话是唯一必须精确的东西）

## 铁律
- 需要原话级别的只有**对方那一句**；你自己的话写"当时大概是X，现在回头看应该这么说"
- 真话是短的、糙的、不完整的；结构工整的一定是现在编的
- 带限定语（"大意是""后面还说了一串我记不清了"）反而更可信
- 禁止：凭空造没发生过的场景；给能被认出的人安没说过的话

## 旧记忆提取（从情绪进，不从内容进）
1. 哪一句话让你当场胃里一沉？
2. 哪一句你事后在车里/地铁上又想了一遍？
3. 哪一句你回家跟人复述过？（复述过的最可靠）
4. 哪一句你当时特别想反驳但没敢？

外部检索源：答辩 PPT 与评委反馈 / 绩效书面评语 / 周报"风险与阻塞"栏 / 抄送很多人的邮件 / 微信吐槽记录（金矿，当时写的就是原话）/ 找当年在场的人聊。

## 当天三行记录法（从今天开始，二十分钟内记）
```
对方原话：
我的回应：
身体反应：
```
不整理、不修辞，语音输入到备忘录也行。素材来源：Pioneer 需求拉扯、报价谈判、教练客户的复述（脱敏后是二级供给主力）。

记满一张卡就补进 案例库.csv 一行；需要提炼成知识原子时用 /eric-atom。
