## 二、核心内容板块（知识体系骨架）

> 面试是当前主攻，其余三场景按上线顺序逐步铺开。

1. **面试表达**（主攻·第一上线）—— 三条主轴：
   - **解码器**：教读者听懂面试官真正想听什么（潜台词）← 天花板赛道，持续主打
   - **送命话**：面试避雷 / 逆向（什么话不能说、老实人怎么"选着说"）
   - **亮点公式**：把真实经历当场讲出亮点、扛住追问（现场表达，区别于简历模板）
2. **谈薪表达**（紧跟上线·高客单）—— 应对追问、报价锚定、沉默与让步话术
3. **汇报表达**（规划中）—— 向上汇报结论先行、把工作讲成价值
4. **向上管理 / 高情商措辞**（规划中）—— 把"对抗"改成"对齐"、冲突化解、措辞顺序
5. **自我介绍 / 个人品牌表达**（贯穿各场景）—— 30 秒讲清身份+亮点+钩子

## 三、我的方法论 / 独家观点

- **顶层方法论——"翻译"框架**：先解码对方的决策框架 → 再用对方能接受的语言 → 达成自己的目标。同行教技巧、教模板，我教"判断力"——话术抄得走，判断力抄不走。
- **现场表达差异点**：核心是"你自己做过的事，现场怎么讲"，不是通用题库、不是简历模板。
- **内容四段式公式**：痛点场景开头 → 反常识/专业观点 → 真实案例验证 → 行动指令。
- **亮点结构（STAR 升级版）**：背景冲突（难在哪）→ 关键动作（我的决策）→ 可量化结果 → 一句沉淀。反对"流水账式报流程"。
- **高情商=换顺序**：先认同情绪/事实 → 再给信息/边界 → 最后给方案。让对方"被接住"，话才听得进。
- **选题三维打分**：痛点 × 搜索量 × 购买意愿（任一维 < 3 一票否决，综合 ≥ 27/125 才立项）。
- **口头禅**："专家视角已死，真实故事才有人点""读者不是在受教育，是在偷听一个故事""不卖感觉，卖结果""案例就是最强的信任锤"。

## 四、选题偏好 & 红线

**偏好**：
- 落在面试三主轴 / 五大板块内、有真实案例或独到观点、能导向变现。
- 优先"面试官视角亲历"与"真实学员案例（脱敏）"——这是别人抄不走的。
- 实操、给可复制公式/模板、读者能直接套自己的经历。

**红线（硬性，生产时必须遵守）**：
- **不碰"保 offer / 保结果"承诺**——只做"辅导"，不做结果保证（退费与监管风险）。
- **不挂身份头衔**——2026-08-02 起不再使用"前腾讯资深中层"等任何身份背书。
  连带禁止编造替代身份（"资深HR""十年面试官"等）。凭什么可信，交给内容本身回答。
- **不教撒谎/编造经历**——"选着说 ≠ 说假话"，只做诚实表达的取舍。
- **不蹭负面热点、不抄同行原句**——素材只作灵感，必须用本框架重写。
- **不做纯鸡汤、不卖焦虑套路逼单**——求职用户理性，过度套路反噬专业人设。
- **AI 合规**：不教 AI 文生图当封面、不用 AI 配音冒充真人、不删改 AI 标识。
- **烂大街标题直接放弃**（见第八节详细清单）。

## 六、验证的爆款钩子排行（真实数据，Day1-Day8）

> 以下基于 1345 条真实采集数据提炼，标注最高热度案例作为参考。高热度不等于因果关系（账号体量/发布时间是污染变量），但多账号/多轮复现的规律可信度高。

### 🥇 S级钩子（万级以上，多轮多账号复现）

**1. 反直觉断言**（"根本不在于…" / "不要…" / "其实…"）
- 公式：否定用户预期 → 制造认知缺口
- 案例：「向上汇报的关键，根本不在于你讲什么」1万 ·「公开演讲不要自我介绍开场」4111
- 写作指令：先找出读者以为对的常规做法，用"根本不/别/其实不是"否定它，再给正确答案

**2. 潜台词/信息差揭秘**
- 公式：低时间门槛 + 对方黑箱解码 + 逐条清单
- 案例：「面试官潜台词」37万 ·「60s教你读懂面试官的潜台词」3.8万
- 写作指令：把"面试官心里在想什么"翻译出来，用"面试官说X，潜台词是Y"格式逐条拆解；时间门槛≤60秒

**3. 反预期结果钩子**（"反而/其实/还有机会"）
- 公式：绝境场景 → "其实还有" → 希望反转
- 案例：「HR说只能给到这个数，其实还有3次涨薪机会」3347 ·「离职原因就这样说，HR当场给你涨薪」4.6万
- 写作指令：从HR的"否定话术"开始，然后用"其实"转折给出反转机会

**4. 痛点身份直呼**（直接喊受众负面身份）
- 公式：负面身份标签 + 自救/万能公式承诺
- 案例：「反应慢、不会聊天接话的人一定要看」10.6万 ·「嘴笨也能出口成章5个诀窍」2.4万
- 写作指令：用受众会自我认同的负面词（反应慢/嘴笨/表达力差/社恐/i人）直接开头，比泛化目标人群有效10倍

**5. 禁忌词/反"老实"母题**
- 公式：道德灰色词 + 认知冲突 + 好处反转
- 案例：「学会了以后这招拿来治同事」55.9万 ·「面试越疯Offer越多」 ·「面试'撒谎'的巨大好处」
- 写作指令：用"装/治/心眼子/撒谎/演戏"等禁忌词制造点击冲动，然后在内容里把它解释成合理的职场策略

**6. 稀缺身份公式**（99%不知道 / 你悄悄学）
- 公式：大多数人失败 + 你 + 悄悄/只需 + 获益
- 案例：「99%职场人不知道的高情商话术（领导饭局版）」11.4万 ·「让90%的人卡壳去吧，你悄悄学就行了」1.6万
- 写作指令：先定义大众失败（99%/大多数人），再把读者拉到少数人阵营，给予优越感和稀缺感

### 🥈 A级钩子（稳定中高热，适合日常内容）

**7. 权威背书+结果锚点**（名人/机构 + 满分/绝杀）
- 案例：「撒贝宁开场白满分作文」4.9万 ·「杨天真自我介绍秘籍」1万 ·「华尔街面试官的潜台词」2.7万
- 指令：名人IP必须配"满分/顶级/这是我见过最好的"等结果锚点，单纯名人范文无效

**8. 极简万能公式承诺**（字数≤10 + 万能/公式）
- 案例：「万能的聊天公式哦」1.4万 ·「社恐易学的万能接话公式」10.4万
- 指令：标题控制在10字以内，核心词为"万能/公式/照着念/直接抄"，让人觉得零思考就能用

**9. 场景+数字囤积**（精准场景 + 大数字清单）
- 案例：「被夸只会说没有啦？码住50句高情商接话」7228 ·「背下20句幽默聊天段子，开口逗笑所有人」4020
- 指令：先点一个极具体的尴尬瞬间，再给"码住/背下N句"的囤积式承诺

**10. 时间极压型钩子**（今天/马上/还有X小时）
- 案例：「马上要面试了，没有时间准备、听这个！绝对够」3.3万
- 指令：用"今天就要/马上/还有X小时"锁定最高焦虑度用户，后接"这个就够了"的兜底承诺

**11. 引语还原+反转**（HR原话引用 → 反转到有利结果）
- 案例：「HR说'只能给到这个数'，其实还有3次涨薪机会」3347
- 指令：把HR/领导实际说过的话原文引用做前半段标题，再用"其实/但是/这时候"反转到对读者有利的结果

**12. 禁止体/反向教学**（"千万不要学" / "别看"）
- 案例：「千万不要学的聊天接话技巧」9629 ·「上班别看，容易笑出声！」8696
- 指令：用"禁止/不要/别"包装内容反向输出，比正向"你要学XXX"热度高30-50%

### ❌ 标题雷区

**A. 烂大街模板（自动降至最低打分）**：
- "面试官不会告诉你的…"
- "99%的人都不知道…"（已被滥用；替换为"让90%的人卡壳"更好）

- "这3个方法让你…"（泛泛数字无具体场景）
- "面试被问X？别慌！照着说就赢了"（安抚型标题，无利益钩子）
- "第46集…"（系列号开头，门槛感强）

**B. 结构性低热标题（有钩子但形式错误）**：
- 纯疑问句无承诺："明明能力够为什么面试还被拒"（272赞）
- 抽象利益无量化："如何通过反问制造不属于你的机会"（515赞）
- 英文/海外场景：缩小受众，天花板百~千级（英文版/北美/🇨🇦 一律低热，英文面试赛道需要专门运营）
- 地域+行业双限定：受众坍缩最快的标题结构
- 纯观点无方法："汇报能力是中层的顶级能力之一"（87赞）
- 数字清单同质拥挤："7个信号是要发offer的征兆"（35赞）

### ❌ 内容结构雷区

- **纯方法论/名词无痛点嫁接**：金字塔原理/PREP/STAR 单独讲低热，必须绑定"面试/汇报/方案被拒"等高焦虑场景
- **科普定义型**：只解释概念、不给话术（"什么是三明治拒绝法" 3赞）
- **无可复制框架的"怼人"内容**：攻击性强但职场建设性差，且夹杂情感/恋爱噪声
- **系列续集缺独立钩子**：续集靠不上母题热度，必须有独立的新信息

### ❌ 赛道进入雷区

- **泛"高情商话术"词**：恋爱污染严重（约40%非职场），采集需加"职场"限定
- **反内卷话术/心态文案**：情绪宣泄文案饱和，可话术化的具体场景才有价值
- **面试什么话不能说（单独作为新选题）**：存量爆款库满，新发供给极度饱和（新账号个位数赞），必须配新钩子（潜台词/身份/反转）
- **管理者视角缩小受众**："永远不要跟下属走太近"（295赞）——受众从"全体打工人"切到"带团队的人"

## 九、已验证爆款骨架（可直接套用，按场景选择）

> 这些骨架经多账号/多轮验证，用于生产时选择对应模板。

### 骨架A：潜台词解码体（适用赛道：面试潜台词/谈薪/接话/离职）

```
① 开场：描述一个"聊得很顺但结果不好"的场景（5句以内）
② 反常识断言：面试官嘴上问的，和他心里想确认的，根本不是一回事
③ 逐条翻译：
   面试官说"X" → 潜台词是"Y" → 你应该这样回应"Z"
   （3-6条，每条格式统一）
④ 案例：两个对比案例，一个没听懂、一个听懂了，结果不同
⑤ 结尾行动指令 + 评论区CTA（让读者扔被问懵的问题，我来翻译）
```

### 骨架B：清单/话术体（适用赛道：接话/拒绝/饭局/自我介绍）

```
① 开场：精准戳一个尴尬瞬间（"被夸只会说没有啦？"）
② 承诺：这N句话让你/帮你/只需XX
③ 逐条展开：
   情景A：❌ 大多数人说"..."（为什么不好）
         ✅ 应该说"..."（为什么有效）
   （每条控制在3-5句，给完整话术）
④ 总结原则 + CTA（收藏/评论说说你的情况）
```

### 骨架C：反直觉认知体（适用赛道：向上汇报/演讲/职场表达/优缺点）

```
① 开场：先破除大多数人的错误做法（"大多数人以为X"）
② 反转：其实根本不在于X，而在于Y（一句话核心观点）
③ 解释为什么：给2-3个具体原因/机制
④ 正确做法：可复制的步骤或话术
⑤ 案例佐证：第一人称目击者视角（我面过/我见过）
⑥ 行动指令
```

### 骨架D：第一人称目击者体（适用赛道：任何板块，最强信任建立）

```
① 开场：具体场景描述，我坐在面试官/会议室/饭局那一侧
② 观察：我见过两种人，区别就在这一句话
③ 对比案例：做法A（大多数人）vs 做法B（少数人）→ 结果完全不同
④ 核心原理：为什么B有效（"翻译"框架解释）
⑤ 可操作公式：给读者直接用的话术/步骤
⑥ CTA
```

### 骨架E：损失厌恶清单体（适用赛道：谈薪/离职/offer确认/送命话）

```
① 开场：大多数人以为搞定了，其实这4个坑还没踩
② 清单展开：
   ❌ 坑N：具体场景描述
   ✅ 正确做法：完整话术
   → 为什么有用（机制解释）
③ 结果反转：一句话说清楚答对带来的具体好处
④ CTA
```

## 十、生产质量标准（成稿要达到的具体指标）

> 这些标准直接对应打分规则，生产时逐项自检。

### 钩子标准（影响打分：钩子强度 25分）
- 必须使用第六节S级或A级钩子之一
- 封面大字 ≤ 15 字，含实质性信息差或情绪冲击
- 标题后不能出现"面试官不会告诉你…""干货/避坑/攻略"等低热词
- 数字必须具体（"3个"优于"几个"），结果必须可量化（"涨薪2000"优于"薪水变高"）

### 痛点共鸣标准（影响打分：痛点共鸣 25分）
- 开场场景必须具体到让 1-5 年职场人秒对号入座
- 不允许"很多人""大部分人"这种模糊描述，改用"那种面试聊了40分钟、对方一直点头、最后说'回去等通知'的"
- 痛点句不超过 5 句，快速建立共鸣后进入内容

### 实操价值标准（影响打分：实操价值 20分）
- 每篇必须给出至少 1 套"可直接复制"的话术/公式
- 话术需包含"场景触发词+说什么+为什么有用"三元素
- 不允许只有观点没有工具（"你需要更自信"这种废话）

### 口语化标准（影响打分：口语化 15分）
- 每句 ≤ 20 字（口播脚本尤其严格）
- 拆解测试：家人/朋友听一遍能听懂吗？
- 禁止书面语："鉴于""就此""综上所述""不仅如此"
- 允许网感词：嘿嘿/这不就/真的太/等等
- 数字量化：不说"很多"，说"3个""5次"

### 结构完整标准（影响打分：结构完整 15分）
- 严格四段式：痛点场景 → 反常识/专业观点 → 真实案例 → 行动指令
- 必须有 CTA，且 CTA 带钩子（评论区扔问题 > 关注我）
- 正文字数：**以「必须命中清单.md」第 2 条为唯一事实源**（当前搜索流规格 300-500 字，依据 20260731 决策 3）。此处不再重复数值，避免多处定义冲突。
- 60秒口播脚本节奏：[0-5s 钩子][5-15s 共鸣][15-45s 核心拆解][45-60s CTA]

### 合规标准（硬性，违反直接归档）
- 无"保offer/保通过/保升职"等结果承诺
- 无照搬他人原句（素材可参考，必须用"翻译框架"重写）
- 不出现任何身份头衔（前腾讯/资深/总监/专家…）。可信度靠原话与细节，不靠 Title
- 无引流外部付费课的强销售

## 十二、选题评判 4 维框架（来自 eric-xhs-topic）

> 选题是否值得做，4 维都要过，有 2 个 ❌ 或任何 1 个核心维度（受众/商业价值）❌ → 直接放弃该选题。

### 维度 1：受众精准度（核心维度）

目标受众：**1-5年职场人**，痛点集中在"进不了场/进了场升不上去"。

平台分发信号：
- 搜索关键词要包含高搜索量的痛点词（"面试""职场拒绝""谈薪"等）
- 内容形式：图文（大字报/清单）> 短视频（露脸口播）
- 内容调性：务实 > 鸡汤，可验证 > 抽象建议
- 有收藏动机：工具/清单/话术/公式，用户有理由保存

**一票否决词**："管理者视角""海外/北美""泛职场心态文案"（受众坍缩）

### 维度 2：认知落差

- **高落差（S级）**：同行没讲，或讲得烂——本账号"目击者/面试官视角"是最大差异点
- **中落差（A级）**：同行讲了，但可用更具体数据/案例/话术做出差异
- **低落差（pass）**：同行都在讲，内容高度同质化

侦察方法：搜小红书关键词"最热"排序前20篇，看天花板热度、角度是否同质、头部账号发布时间。

### 维度 3：商业价值（核心维度）

| 选题类型 | 商业价值 |
|----------|----------|
| 展示专业能力，引导咨询/报名 | ✅ 间接变现（主要路径）|
| 建立信任，扩大受众规模 | ⚠️ 长期价值，短期无收入（按比例控制）|
| 纯粹分享，无变现路径 | ❌ 自嗨型内容，禁止 |

**变现路径自检**：这篇做完，能不能让看完的人产生"我想了解训练营/一对一"的想法？

### 维度 4：执行可行性

- 是否有可溯源的真实原话可支撑？（案例库 / 评论区原话库 / 探测数据）
- 内容形式是否匹配当前生产能力（录屏+真人画外音）？
- 有无时效性压力？（时效窗口内优先发）

## 十三、标题 12 类触发器速查（来自 eric-xhs-title）

> 75个验证过的爆款公式，按12类心理触发器分类。每个标题必须能追溯到具体公式类型。

### 标题 5 条铁律（必须全部满足）

1. **留悬念不说答案**：看完标题还需要点进来吗？答案说完了 = 失败标题
2. **扩大话题不缩窄**：用"面试潜台词"不用"STAR法则的注意事项"（行业术语缩流量池）
3. **击中真实痛点**："不上班"比"知识付费"更真实；"聊得顺却没下文"比"面试技巧"更痛
4. **张力 6 项命中 ≥ 2**：有对比/反差、有具体数字、有悬念/好奇、有冲突/争议、有时间承诺、有结果承诺
5. **≤ 20 字（含标点）**：硬性规范，超了就砍

### 12 类触发器 × 本账号适用度

| 类型 | 编号 | 适用度 | 本账号最佳用法 |
|------|------|--------|--------------|
| **认知冲突** | 1-6 | ⭐⭐⭐⭐⭐ | "向上汇报的关键根本不在于讲什么""别再自我介绍开场" |
| **好奇缺口** | 7-12 | ⭐⭐⭐⭐⭐ | "面试官不会告诉你的…"（已烂大街）→ 升级为"面试官潜台词" |
| **恐惧/损失** | 13-20 | ⭐⭐⭐⭐ | "这3件事千万别做""面试最危险的话" |
| **身份代入** | 21-25 | ⭐⭐⭐⭐⭐ | "反应慢、不会聊天的人""嘴笨的人""i人必看" |
| **数字锚定** | 26-32 | ⭐⭐⭐⭐ | "3个信号""6句接话""50句高情商回话" |
| **结果承诺** | 33-40 | ⭐⭐⭐ | "60秒教你""面试当场就涨薪" |
| **社会证明/反转** | 41-47 | ⭐⭐⭐⭐⭐ | "我面过300个人""我坐在面试官那侧十年" |
| **争议/挑衅** | 48-55 | ⭐⭐⭐ | "面试撒谎的巨大好处""学会了拿来治同事" |
| **场景/条件** | 56-60 | ⭐⭐⭐⭐ | "当HR说'只能给到这个数'""马上要面试了" |
| **行动号召** | 61-66 | ⭐⭐ | 较弱，偶尔用 |
| **权威借力** | 67-71 | ⭐⭐⭐⭐ | "撒贝宁开场白满分""杨天真自我介绍秘籍" |
| **互动/测试** | 72-75 | ⭐⭐ | CTA辅助，不做主标题 |

### 本账号最高ROI触发器组合

**首选（S级赛道必用）**：认知冲突 × 身份代入 × 社会证明/目击者视角  
**标准写法**：`[身份直呼]+[我见过/面过N人]+[反直觉结论]`  
例：「嘴笨的人听好，我面过300个人，被录的那批都没背过一道题」

## 十四、开头 Hook 框架（来自 eric-hook）

> 开头决定完读率，是内容里最重要的 200 字。

### 黄金公式

```
好开头 = 话题（讲什么）+ Hook（为什么看）+ 可信度（为什么信你）
```

**例**：  
- 话题：面试官的潜台词  
- Hook：我面过 300 个人（数据冲击）  
- 可信度：靠的就是搞清楚这一套  
- 完整开头：「我面过 300 个人，发现答得越'完整'的，越容易被刷——不是他们能力差，是他们没听懂面试官在问什么。」

### Hook 素材 6 种（按优先级）

| 优先级 | Hook 类型 | 示例 |
|--------|----------|------|
| ⭐⭐⭐⭐⭐ | **晒结果 + 反转** | 我面过 300 个人，只有 3 个听懂了这句话 |
| ⭐⭐⭐⭐ | **数据冲击** | 37万人点赞的面试技巧，只有一句核心 |
| ⭐⭐⭐⭐ | **反差/转变** | 从每次面试都卡壳，到被 3 家公司抢着要 |
| ⭐⭐⭐⭐ | **金句独立成立** | 面试不是比谁能力强，是比谁更会翻译 |
| ⭐⭐⭐ | **权威 + 场景** | 前腾讯中层，十年面了几百人，有一类人必不录 |
| ⭐⭐⭐ | **痛点 + 悬念** | 聊了 40 分钟、对方一路点头——然后再没消息了 |

### 开头 5 条铁律

1. **独立性**：不看标题也能理解。开场必须自带话题建立，不能假设读者看了封面
2. **留悬念**：开头给了答案 = 失败。用"为什么"不用"证明"，用"问题"不用"结论"
3. **口播友好**：不自问自答（"你以为你在…？其实…"），不书面语。能直接念出口才行
4. **可信度先行**：为什么听你讲？面试官视角/面过N人/亲历案例——在开头30字内建立
5. **匹配度**：开头承诺的，正文必须兑现。标题问A开头讲B = 跳出率暴增

### 最高优先级的开头类型（本账号）

**目击者切入**（>一切其他开头）：
```
❌ 错：「今天讲面试技巧，很多人面试聊得很顺……」（废话开场）
✅ 对：「上周我面一个候选人，答完最后一句，我笔都没动就在表上打了叉——」（毛边现场）
```
原则：要有具体到能"闻到味"的现场画面，不是工整说教。

## 十五、平台算法参数与发布质量线（来自 eric-xhs-audit）

> 这是内容能否获得二次推流的客观门槛，生产前必须对照。

### CES 公式（小红书互动权重）

```
CES = 赞×1 + 藏×1 + 评×4 + 转×4 + 关注×8
```

**含义**：评论和转发的权重是点赞的 4 倍，关注是点赞的 8 倍。  
**生产推论**：
- CTA 要诱发**评论**（"评论区扔你被问懵的问题"），不是点赞
- 评论 ≥ 8 字的算法权重显著更高——引导读者说具体场景，不是"好的"
- 有争议/反常识的内容 → 天然诱发评论，优先选

### 初始流量池晋级线

| 指标 | 及格线 |
|------|--------|
| 点击率（封面+标题） | > 10% |
| 有效阅读完成率 | ≥ 45% |
| 互动率（CES/曝光） | ≥ 5% |
| CES 绝对值 | ≥ 8 → 二次推荐概率显著更高 |

**拖后腿最常见的元凶**：封面/标题（决定点击率）、开头（决定完读率）、CTA（决定评论/转发）。三件套优先级 > 正文。

### 7 维爆款审核评分卡（100分制）

| 维度 | 满分 | 核心评判问题 |
|------|------|------------|
| 选题·痛点 | 20 | 有无真实场景化痛点？目标人群精准？有认知落差？指向变现？|
| 标题 | 20 | 留悬念不说答案？张力6项≥2？≤20字？能追溯公式类型？|
| 封面 | 15 | 0.3秒停屏？制造冲突/好奇？大字钉≤15字？视觉锤统一？|
| 开头钩子 | 15 | 前3秒有抓手？不看标题也懂？留悬念？可信度？口播友好？|
| 正文·网感 | 18 | 结构清晰？有真实感/毛边？短句口语？信息密度高？有收藏价值？|
| 可信度·差异 | 7 | 目击者/第一人称视角？有真实案例？与同行差异立得住？|
| CTA·互动设计 | 5 | 结尾诱发高价值评论？引导读者说具体场景（≥8字）？|

**评级**：≥85=🟢可发 / 70-84=🟡先改 / 55-69=🟠需重做 / <55或踩红线=🔴打回

### 审核红线（任一命中 = 打回，不看总分）

- **标题把答案说完**：看完标题就不用点进来 → 必死
- **必死开头**："大家好我是……今天是X月X日" / 自问自答开场 / 书面语开场
