# 答辩被问为什么选这个课题，千万别说感兴趣

"虽然但是，为什么选择这个课题，这答案真的是硬着头皮乱说话大学四年一直专注这个课题，很感兴趣sos要撒这么假的谎，i人表示太为难了一定要这么答吗"

这是评委一听就皱眉的开头。评委坐在台下，一天要听几十个选题。当他问你为什么选这个课题时，他耳朵里在过滤两件事：第一，这不是你为了凑毕业硬编的；第二，这个方向在行业里还有没有往下挖的缝。

你一张嘴就是"我很感兴趣"，评委手里的笔就停了。在评委看来，兴趣不值钱，能落地、有数据、导师给的框架能闭环才是真的。

图里这三类回答，对应了三种真实的翻车现场。

第一种是老实交代型。你说自己基础薄弱、导师让干啥就干啥，评委直接在心里打了个叉：创新性在哪里？

第二种是假大空型。你硬编一个高大上的行业痛点，结果被追问两句技术指标，当场大脑一片空白，舌头打结。

第三种是清醒克制型。你把选题背后的约束条件和导师的底层框架亮出来——（你是哪一种？A 兴趣驱动硬编　B 导师硬塞不会说　C 常规课题找错位，记住你的答案）。

真话怎么说？别装作这是你独立萌发的伟大灵感。你可以直接认领：这个选题是在现有工科框架下，结合导师前期积累的项目推进的。

（你是哪一种？A 兴趣驱动硬编　B 导师硬塞不会说　C 常规课题找错位）。

把兴趣换成边界，把宏大叙事换成具体的技术卡点。评委不是来审判你的真诚的，他是来验收你的交付能力的。

说到底，这考验的是你的结构力：用对方能接受的框架，把一个并不性感的常规选题，讲出它在特定约束下的真实价值。

回个字母就行：
A. 导师硬塞的题目，完全不知道怎么包装创新点
B. 选题太常规，说真话怕被评委喷肤浅
C. 压根没想那么多，就是随大流选了个能毕业的
