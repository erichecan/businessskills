2
定位结论 · 能力为体,场景为用
这是项目最核心的一次校准

最容易跑偏的地方:要么只讲「面试技巧」(太通用、没壁垒),要么只盯「拿 offer」(把自己做成中介,没复购)。最终校准为一句话:

能力为体 · 场景为用

能力(体):教面试表达力——这是核心、是差异化、是别人没占的位。

场景(用):求职拿 offer 是第一个落地场景、是结果交付;职场表达是能力延伸线、是复购。

先用「拿 offer」这个最痛的场景把人引进来、做出结果建立信任,再把能力延伸到更长的职场表达,完成从一次性到长期的跨越。

3
差异化护城河
为什么用户选你,而不是满屏的面试 / 简历博主

市场现状:讲面试技巧的多(太通用,用户觉得"没说到我的问题"),讲改简历的也多(讲的是纸面包装)。几乎没人从"现场表达"切入。

差异点:现场表达

教用户怎么把自己真实做过的事,当场讲出亮点、扛得住追问。面试现场真正的命门不是技巧——是"说几句就卡壳、怕被追问、讲不清自己的贡献"。这正是通用技巧和简历模板都解决不了的。

打法:用「面试送命话 / 避雷图鉴」这类逆向钩子起号(易传播),内核是表达解码器框架(教用户听懂面试官想听什么),原料是你的真实学员案例库。

护城河 01
真实腾讯背景

前腾讯 PM / 面试官,信任感天然,新人难复制。

护城河 02
可交付的结果

不止讲内容,能把人带到拿 offer,结果可衡量。

护城河 03
在岗导师网络

1v1 在岗导师资源,是交付端的硬壁垒。

4
核心方法论 · 博商工业化四齿轮
整个工厂图纸都建在这四个齿轮上

博商打法的精髓,被提炼成四个互相咬合的齿轮,也是 eric-boshang 质检 skill 的四道关:

⚙️ 产能

1 个母体 → 切 N 条;靠量不靠单条。"撒网捕鱼"不是"钓鱼"。

⚙️ 内容公式

语言钉标题 + 冲突故事 + 模糊结论(导流)+ 视觉锤。

⚙️ 赛马

多版本同发 → 看数据择优 → 复制爆款结构(AI 降维做 AB)。

⚙️ 漏斗

产品阶梯 + 单粉价值核算;每 N 条引流插 1 条变现。

质检 skill → eric-boshang/SKILL.md(每道工序的"质检员",不达标打回)

5
可迁移性红线
博商哪些能抄、哪些不能抄——别照搬大厂打法烧死自己
✓ 可迁移
逻辑与方法

漏斗钩子 / 单粉价值 / 赛马式 AB / 长尾不丢人 / 用大众语言讲专业。

✗ 不可迁移
人海与资本

百账号矩阵 / 亿级投流 / 电销人海 / 多老师线下大课——个人做不了。

⚠ 赛道命门
求职特有

用户买"确定性结果"非内容;退费率高需双轨合同;合规红线(禁裸宣传"100%保offer")。

8
关键决策记录
项目过程中的几次重要转折,记下来防止以后又跑偏
  • 从"大方向对但不够细"到工业级图纸

    博商核心玩法方向认可,但要求做到有图纸 / 检验标准 / 数据标定 / AI 自动化 / 放大化的工业级别,且产出为 HTML(可浏览性强)。

  • 诚实能力审计,而非假设

    一度按"多平台自动抓取""eric-content 能代写"来写 SOP。逐个读代码 / 派 agent 验证后发现并非如此,全部改为写实 + 人工兜底。原则确立:先验证再写。

  • 业务底座的全面重建

    一度把项目做窄成"只教面试表达",丢了业务底座。结合外部博商调研报告,确认真实业务 = 前腾讯 PM 求职辅导(真背景+结果交付+导师网络),全面重建定位 v2。

  • 回归"能力为体场景为用"

    重建后又过度偏向"拿 offer 中介"。再校准:不能只有面试,要回归教面试表达这个能力内核——最终定型为能力为体、场景为用。

  • 抄袭顾虑的破解

    担心"逆向选题易被抄"。结论:护城河不在单条内容保密,而在解码器方法论 + 真实案例库 + 信任交付 + 博商赛马体系的组合。

  • 每道工序补成"X 步作业书"

    选题不能只有方向、没有步骤。要求每一道工序都按统一标准补成 X 步作业书,13 道工序全部落地为可执行 SOP。

  • 用真实案例跑通 L1 验证独特性

    需要一个真实案例跑通全流程,验证"现场表达"方向确实做得出别人做不出的内容(无通用技巧、无简历模板套话)。

  • 内容形态定调:录屏 + 真人画外音

    小红书对 AI 内容强制标识、未标识/低质 AI 限流(隐式水印不可删改,删改属违法)。结合"不想露脸",定调录屏 + 真人画外音:既躲 AI 限流、又不露脸、还与口述母体工作流天然咬合。禁 AI 配音 / 文生图。详见录屏画外音作业书。

9
第一周怎么开干
物料已齐,照着这条线走

第一周只赌一件事:把 1 个母体 → 5 条内容 → 发出去 → 看数据。不追求爆款,追求跑通流程 + 验证方向。

  1. 开跑前装备:账号(小红书主+视频号)、视觉锤模板、3-5 个真实案例(脱敏)、私信首响话术 —— 物料都在交付物里
  2. Day1 选题:锁母题"现场表达",拆 5 个具体场景,每个配一个真实案例,起语言钉标题
  3. Day2 母体:对着 5 个选题一次性口述录制(不写稿),AI 转写存母体库
  4. Day3 脚本+切片:转四段式脚本(痛点→观点→案例→行动),留私信钩子,切 5 条
  5. Day4 成品:套封面模板,过 AI 味检测,每条发布前过 eric-boshang 四齿轮质检
  6. Day5 发布:错峰发小红书+视频号,挂私信钩子,本周只引流不卖货
  7. Day6-7 承接+复盘:回收数据(私信数最重要),用话术接住+打标,复制数据最好的结构
成功基准线(达到任一即"方向跑通"):5 条全部产出发布(底线)/ 单条 24h 赞藏破 100-200 或带来 5-10 个私信加微 / 评论区出现"求模板、怎么找你、说到我了"。
