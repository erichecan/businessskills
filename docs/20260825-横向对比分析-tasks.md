# 横向对比分析 — 任务台账

> 目标：把「单篇打分」「观看量预测校准」之外缺的一环补上——本账号自己的横向对比，
> 回答"什么话题/标题模式/口径/卡片结构，实际拉高互动率"，结论反馈进写稿 skill。
> 本台账是进度唯一真相，每周期从这里读起，做完回写状态。

## 任务列表

### T1 · 建立可关联的宽表（关联脚本）
- 产出：`scripts/xhs-loop/cross_section_report.py`
- 输入四源：
  - `xhs/素材库/审核记录.csv`（成稿文件→7维分/口径/处置，同文件多行取"发布"处置对应的最后一行）
  - `xhs/素材库/成稿_*.md`（头部 `> 角度` `> 口径` `> 关键词`、正文首段"发布标题"里的【首选】标题）
  - `xhs/素材库/图文_*_cards.json`（卡片 type 序列、quote 是否非空、pose 分布——文件名日期+主题slug 与成稿文件确定性匹配）
  - `xhs/素材库/发布数据.csv`（按标题模糊匹配回成稿，取该笔记"满7天"或最新一行做终值快照）
- 输出：`xhs/素材库/横向对比宽表.csv`，一行一篇已发布满7天的稿子，列含：
  成稿文件,发布标题,话题类别,角度是否声明,口径,标题模式,7维分,是否用quote金句,卡片数,观看,点赞,收藏,评论,分享,搜索占比,收藏率,互动率
- 验收标准：宽表存在；行数与"审核记录处置=发布 且 发布数据满7天有数"的交集数一致（先跑一遍数出预期行数）；人工抽查 3 行，成稿文件↔发布数据标题确认对得上。
- 依赖：无，先做这个。

### T2 · 补两个当前没有结构化字段的标签
- 话题类别：用 `场景地图.csv` 的 `匹配词` 列做关键词匹配，映射到 `阶段+场景`；匹配不上的标"未分类"。
- 标题模式：对照 `知识框架.md` 第六节钩子分类（反常识/数字悬念/身份错位/旁观目击/细节震撼/常识颠覆/其他），对每篇"发布标题"人工判定标签，直接并入 T1 脚本产出的宽表。
- 验收标准：宽表里两列均非空（"未分类""其他"允许存在但要能数出占比，占比过高说明分类体系要调整）。
- 依赖：T1 的标题抽取部分。

### T3 · 分桶统计 + 产出复盘
- 产出：`xhs/素材库/横向对比复盘.md`，格式仿 `预测复盘.md`（桶A中位数 vs 桶B，样本数，判定，结论）。
- 分桶维度：话题类别 / 口径 / 标题模式 / 角度有无声明 / 是否用quote金句 / 卡片数分档。
- 校准纪律沿用既有规矩：单桶 <5 篇只记录不下结论；≥5 篇才允许写成"下一步怎么做"的执行指令。
- 验收标准：每个分桶维度都在文档里出现，且明确标了样本数；结论句是可执行指令，不是描述性观察。
- 依赖：T1+T2 产出的宽表。

### T4 · 反馈进写稿 skill
- 在 `skills/eric-content/SKILL.md` 和 `skills/eric-xhs-title/SKILL.md` 里加"写稿前必读"引用，指向 `横向对比复盘.md`，机制比照条款I（写稿前读审核记录最近5行）扩展为"写稿前读上周横向复盘"。
- `知识框架.md` 第六节钩子库逐条补注"本账号已验证：有效/无效/样本不足"（当前标注为"他人账号采集，本账号未验证"）。
- 验收标准：两个 SKILL.md 文件可见新增段落且路径正确；知识框架第六节钩子条目旁出现验证状态标注。
- 依赖：T3 出结论后才能标注"有效/无效"。

### T5 · 待定，不在本轮做
- 封面 A/B 测试机制（同选题发两版封面对比）——需要额外发布成本，需 Eric 决定要不要投入，先记在这里不排期。
- 复盘更新节奏（每周自动跑一次 vs 每满5篇新数据跑一次）——等 T3 跑出第一版看实际数据密度再定，不预先假设。
