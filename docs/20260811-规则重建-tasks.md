## T13 基准测试：拿外部真爆款反测新标准（⚡ Eric 要求先于下一周期完成）

Eric 08-11：「用新的写稿标准和新的审核标准，去找一篇采集回来的高赞笔记，
看看你能不能写出一个类似的；另外用审核的标准，看看高赞的笔记得多少分。
把这两个做完了再做下一周期，要把发现的问题、总结出来的经验都补充到整个写稿和审核里。」

**为什么这个测试比再等发布数据更快**：自有配对样本只有 17 篇（已停用），
而采集库里有**现成的真爆款 + 真数据**。尺子准不准，拿真爆款一量就知道 ——
如果尺子给日均 500 赞的爆款打低分，问题在尺子；如果照标准写不出类似的东西，问题在写稿标准。

**基准选择**：`面试时不要太老实！这样回答才加分`（11000 赞 / **日均 500 赞** /
去标签后正文 418 字）—— 32 篇采集爆款里**唯一一篇既高热、正文又够长**的，对照最公平。

**已发现（跑测试前就查出来的）**：
- ⛔ **32 篇高赞笔记去掉标签后，正文字数中位只有 60 字**；
  **27/32 篇低于 300 字**（我们的硬性下限），23/32 篇低于 100 字，10 篇是 0 字。
  日均赞前三名（3750 / 1527 / 692）的正文分别是 **0 / 0 / 69 字**。
  → 若这批真爆款进我们的流水线，**27 篇在第一道机械检查就被打回，进不了审核**。
  → 「正文 300-500 字」来自 20260731 决策 3（Eric 拍板），不是数据。需重新裁定。

**验收**：
- [ ] 审核侧：外部爆款实测得分 + 扣分点，且扣分点要分成
      ①真实质量差异 ②体系性错配（拿不到我们的素材库/卡片而被扣的）
- [ ] 写稿侧：用新标准写同题稿，与爆款逐项对比（结构/钩子/CTA/可信度来源）
- [ ] 把发现补进写稿标准与审核标准，**不是只写进文档**
- [ ] 测试用的临时成稿文件用完即删，审核结果**不写入 `审核记录.csv`**（避免污染统计）
