## Eric 的五条原话（不要改写、不要软化）

1. **不要人工把搜索位有空缺的标成已验证，自动标已验证。**
2. **待验证是什么逻辑，我个人觉得不需要待验证，成稿后发布，让市场去检验。**
3. **候选词积压 >200，你计划如何处理，我希望能尽快变成成稿。**
4. **成稿标准加数据预测**：联网搜小红书爆款技巧+官方规则 → 每篇成稿预测数据 →
   拿到回填数据后自己 review「当时为什么没预测准、怎么能更准」，含评论/转发/收藏。
5. **推荐流不能废弃**：推荐流不做视频，但按原成稿路线做图文，账号内容丰富度才起得来。
