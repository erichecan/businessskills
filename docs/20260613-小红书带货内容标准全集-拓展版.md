## 总框架（原文三层逻辑）

> **原文**：「它是从连接点到产品独特优势的一个故事线……这是第二组标准……第三组标准就是……我凭什么相信你。」

全集按内容生产的**先后顺序**重排为 6 组：
1. 选题与连接点（决定能不能被点）
2. 开篇与封面（前 2–3 秒）
3. 代入感（要素堆叠）
4. 故事线（向往 → 非他不可）
5. 让用户相信（信任）
6. 终点与价值（爆 / 涨粉 / 卖货）

## A 区 · 原文可支撑的标准

### 第 1 组｜选题与连接点

| 编号 | 标准 | 原文摘录 |
|---|---|---|
| S1 | **找到「用户心目中早已存在的需求 × 产品」的连接点** | 「用户心目中早已存在的需求，和你这个产品中间的连接点。」 |
| S2 | **连接点冲突时「选强不选广」** | 「在广和强中间发生冲突时选择强，不要选择广……如果你广而弱，那这个东西就没戏了。」 |
| S3 | **连接点选更易点击的类型**：大菜 > 家常菜、西餐 > 中餐、中产兴趣 > 日常 | 「西餐就强过中餐，大菜强过日常的菜，更符合中产兴趣的就会强过更符合日常的……所以大菜就比家常菜安全。」 |
| S4 | **从目标人群兴趣里海量搜集，再连线到产品** | 「从这个目标人群的兴趣里面，去海量搜集兴趣。最后来看哪一个兴趣我有可能通过这个产品实现……它是个海量搜集之后的连线问题。」 |
| S5 | **种草型内容优先于横测**（横测只适用于已进入搜索状态的用户） | 「在小红书上大多数品牌它希望破圈和提高销量，最需要做好的这类内容还是种草型的内容……（横测）只适用于特定场景。」 |
| S6 | **抢前端注意力**（种草的人通常也覆盖了后续搜索） | 「做唤起需求、做种草的那个人，他肯定后面的搜索大概率他也覆盖了……所以你还是要抢前面的那个注意力。」 |
| S7 | **开头不要先讲产品** | 「他在卖那个料理机的时候，这条内容一上来，他就没有先讲料理机。在他的头一分钟你就看不到那个料理机的存在。」 |

### 第 2 组｜开篇与封面（前 2–3 秒）

| 编号 | 标准 | 原文摘录 |
|---|---|---|
| S8 | **开篇先回答「我为什么点进去 / 为什么代入」** | 「开篇你要解决的第一个问题叫做我为什么点进去和用户为什么代入。」 |
| S9 | **先拆「什么是一个诱人的 X」= 锁定核心体验要素**（吐司=香甜/软/不噎） | 「他先用做消费品一样的思路拆解了什么是一个诱人的吐司……基本上关联于三个要素。」 |
| S10 | **头 3 秒把核心体验直观化展示**（尤其难直接说清的体验） | 「他头 3 秒钟的这个任务叫做怎么将这三个体验，特别是后两个体验展示出来。」 |
| S11 | **用「具象动作」可视化抽象体验**（软=筷子一夹软塌下来的形变） | 「筷子一夹软塌塌下来了，巨大的形变是不是看起来就软。」 |
| S12 | **用「反义词」给产品命名，打消用户顾虑**（怕噎→「高水量吐司」） | 「用户核心的那个顾虑，你就用他的那个反义词把它打消掉……他就把他的这个吐司命了一个名，叫做高水量吐司。」 |
| S13 | **封面要让人「莫名觉得更好」**（用户不分析，但一看就觉得对） | 「头 2 到 3 秒你看到封面的时候，你就觉得说莫名的这个吐司就更好吃。因为用户不会这么分析。」 |

### 第 3 组｜代入感（要素堆叠）

| 编号 | 标准 | 原文摘录 |
|---|---|---|
| S14 | **堆叠越多相似点，命中越深** | 「我把这些相似点我在整个内容中植入的越多，命中一个人的这个深度就会越强。」 |
| S15 | **相似点必须全程一致**（前像后不像，代入感反降） | 「你在这三年与我相似，但后三年不与我相似，它的代入感反而不增，然后反降。」 |
| S16 | **世界观要与目标用户呼应** | 「我们与这个人的世界观中间更多的地方能够有所呼应，他所创作的欣赏感就会越强烈。」 |
| S17 | **满足朴素价值观：善恶有报** | 「中国用户在内容中间的一个朴素价值观，叫做善恶有报，善有善报，恶有恶报。」 |
| S18 | **反派要「搬起石头砸自己的脚」，好人不过度报复** | 「必须是反派搬起石头砸自己的脚。反派必须要提前被铺垫，他最在意什么……一定要让他失去这些东西。」 |

### 第 4 组｜故事线（向往 → 非他不可）

| 编号 | 标准 | 原文摘录 |
|---|---|---|
| S19 | **先让用户对体验建立向往**（这道菜越好吃，产品越被需要） | 「这道菜越好吃，这道菜越能让这个人唤起欲望，他就后面那个料理机他也就会越需要。」 |
| S20 | **解决方案要导向「对产品独特优势的必然需要」** | 「在描述解决方案的过程中，让大家倒向对这个产品独特优势的必然需要。这个东西一定要是必然的。」 |
| S21 | **产品 = 实现体验的「救世主」，非他不可** | 「它就像是帮助你实现这个体验的救世主一样，非他不可。只有他在这个时间出现，然后才能够解决这个问题。」 |
| S22 | **拿掉产品内容不成立，才算达标故事线** | 「一旦拿掉这个产品，这个内容不成立了，它的这个故事线才是一个达标的故事线。」 |
| S23 | **产品独特优势也要直观化**（噪音低→小熊不点头 / 水不晃） | 「噪音低，它展示的是……上面放了一个玩偶，小熊说小熊不会点头又直观化了……上面放一杯水……水就不会晃。」 |
| S24 | **效果外化优先级：视觉 > 文字、比喻 > 平铺、唤起感受 > 硬说明** | 「能用视觉传达的就好过用文字传达，能用比喻的就好过平铺直叙。能用这个唤起用户感受的文字描述的就好过向用户的硬的说明。」 |

### 第 5 组｜让用户相信（信任 = 第三组标准）

| 编号 | 标准 | 原文摘录 |
|---|---|---|
| S25 | **让用户自己形成结论，不要你来说服** | 「让用户自己形成结论，不要你来说服。」 |
| S26 | **给信号让用户自己得出结论，再用你的话复述**（葫芦→福禄） | 「你看我这是八个葫芦串成一串，看到这个有没有想起福路连接……他会共鸣，他不会对抗。」 |
| S27 | **避免「硬贴标签」式说服**（直接说"很吉祥"会引发对抗） | 「你就相当于你在硬告诉别人说这个东西很吉祥……用户就很容易和你建立这个对抗的一个情绪。」 |
| S28 | **达人人设要有权威性**（看起来像干什么的就卖什么） | 「这个达人的人设权威性。就这个人看起来像是干什么的，他就卖什么。」 |
| S29 | **人设不匹配时，换一个有权威的切入角度**（运动达人→运动新手踩坑） | 「不讲说我是运动达人……而是讲我是运动新手，在刚刚开始运动时，发现踩到最痛的三个坑是怎样……他这个人设也是可以的。」 |
| S30 | **感染力：嗓音 / 情绪要匹配场景**（春节→嗓音尖更喜庆） | 「我们发现嗓音更尖的达人带货效果会更好……春节是喜庆的……第一个听起来更喜庆。」 |
| S31 | **达人戏路匹配内容情绪**（松弛感找圆脸夫妻；冲动情绪找精致尖嗓） | 「夫妻两口子都是圆脸，笑起来就是很让人有安全感，很有松弛感……另外一类人……嗓音也更尖……去渲染起这个冲动的情绪就会更合适。」 |
| S32 | **善用「不相关但被认为相关」的符号**（手表+大狗=优雅；铅笔不倒/水不晃） | 「戴着手表和手链旁边摸一个大狗狗，内容点击率就更高……你加上这个符号……接受度就会更高。」 |

### 第 6 组｜终点与价值

| 编号 | 标准 | 原文摘录 |
|---|---|---|
| S33 | **先明确内容类型的「终点」**（带货 / 涨粉，交付物不同） | 「它本质上它是不同的终点，决定了不同的内容类型的交付。」 |
| S34 | **带货链路：渲染渴望 → 救世主 → 必然选择** | 「我们渲染起了用户渴望实现的一个状态……因此我们作为救世主，我们帮他解决了这个问题……他就会导向必然选择。」 |
| S35 | **涨粉链路：让用户预期你能「持续创造价值」** | 「用户是否看完这个内容之后，再看了你的这个个人主页，他会预期你能够持续为我创造某种价值。」 |
| S36 | **涨粉链路：建立「稀缺性」**（别人做不到你这么好） | 「这个价值你是否创造的有独特的优势，就你是否有稀缺性……大概率没有别人能够做的比你更好，那倒下的就是订阅了。」 |
| S37 | **触达量决定涨粉上限**（看不到就不会关注） | 「你的内容能够触及多少人，它是你的涨粉的上限，内容都看不到，他肯定就更不会关注你了。」 |
