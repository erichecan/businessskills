# 20260816 职场表达场景版图 —— 从「求职表达力」打开到「职场表达力」

> 起因：Eric「职场表达力就是面试、答辩这点事情吗？还有很多很多场景」。
> 查证属实，而且比感觉更糟 —— 收窄是**结构性**的，不是偶然。

## 一、收窄有多严重（实测）

| 口径 | 数字 |
|---|---|
| 已发布 22 篇 | 面试 8 · 答辩述职 4 · 日常协作 5 · 空降 3 · 谈薪 2 |
| 已验证 83 词 | **面试类 40 个（含面试后判读/面试禁忌/反问环节），占 48%** |
| 关键词池种子 | 4 个，其中 3 个是面试词 → **采集漏斗 75% 的入口是面试** |

## 二、根因：种子词决定一切，而种子既窄又饱和

`daily_collect.pick_keywords()` 原本是 `seeds[:4]` —— **无序切片**。
池子里排在前面的那 4 个种子每轮必投、永远只投它们：

| 种子词 | 运行次数 | 最近几轮命中率 |
|---|---|---|
| 职场表达 | 169 | 0% / 0% / 6.7% |
| 面试技巧 | 170 | 5% / 0% / 0%「饱和」 |
| 面试什么话该说 | 169 | 0% / 0% / 0%「饱和」 |
| 面试什么话不能说 | 170 | 0% / 0% / 25% |

**跑了 170 次、命中率掉到 0，还在每天投。** 而且新加的种子若不改排序，
会永远排在后面、一次都投不出去。

最讽刺的一条：「职场表达」的备注里自己写着
**「前排被"职场会接话"原句变体继续占位」** —— 系统早就发现了这个词，
却没有任何环节把它提成种子。

## 三、非面试场景的天花板高一个数量级（记忆库 5120 条实测）

非面试类 2105 条，占 41%。热度 TOP：

```
55.9万  学会了以后这招拿来治同事
23.4万  如何跳出自证陷阱？3步完美反击！
12.7万  职场会接话的重要性
10.7万  反应慢、不会聊天接话的人一定要看
 9.5万  7个反内耗社交心法，让你戒掉弱者气息
 8.9万  你容易紧张，可能不是因为胆小
 7.1万  表达能力，决定了你的职场上限
 4.7万  弱者表达习惯替换表
 4.2万  甩锅小连招
```

对照面试类最高：8.4万（面试一定要会反问）、5.9万（通过率100%的面试技巧）。
**主力一直放在天花板最低的那一块。**

## 四、已执行的改动

1. **修 `pick_keywords` 种子不轮换的 bug** —— 改为按「最近运行」升序，
   与 active/cands 一致。不改这条，新种子永远投不出去。
2. **种子池 4 → 9 个**，面试占比 75% → **33%**：

| 新种子 | 依据 |
|---|---|
| 职场接话 | 接话簇 116 条、中位 251 全场最高；「职场表达」备注已点名该词占位 |
| 职场回怼 | 回怼簇最高 55.9万，全库天花板 |
| 开会发言紧张 | 紧张簇 120 条；场景具体，不易串到非职场 |
| 职场甩锅 | 甩锅簇 84 条、最高 4.2万 |
| 弱者表达（活跃→种子） | run3 命中率 **90.0%（18/20）全场最高**，却 11 天没投 |

   「向上管理」保持活跃不升 —— 命中率仅 5.9%，数据不支持。

3. 下一轮 `daily_collect` 会投：职场接话 / 职场回怼 / 开会发言紧张 / 职场甩锅
   （4 个全新词），饱和的面试词排到最后。

## 五、还没做的

- **表达力/说话之道（386 条）· 汇报述职（170 条）· 领导关系（172 条）**
  这三簇样本最多但热度字段缺失严重，判不了。需要补采热度后再决定是否提种子。
- 泛词串场风险要盯：历史教训是「高情商表达」串到撩对象/哄老公（命中率仅 ~35%）。
  新种子里「职场接话」「职场回怼」「职场甩锅」都带了职场限定，
  但仍需看首轮相关性过滤后的命中率，低于 40% 就要改写更精确的 query。
- 场景扩了之后，**答案空缺的探测口径**是否要跟着调整（现在的 probe 提示词偏面试）。
