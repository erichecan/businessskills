# 搜索流转向决策与实施方案

> 依据：2026-07-31 与 Claude 的战略对话（claude.ai/share/6588c37a）。本文档是后续所有任务提示词、skill、app 改造的顶层依据，优先级高于知识框架 v5.0 中与之冲突的条款。

## 七条已定决策

1. **收缩关键词，做搜索流**：放弃推荐流爆款竞争，做四五节长句长尾词（"晋升答辩被问倒怎么办"）。好词三条件同时成立：有下拉补全 / 笔记数不为零但不多 / 前排赞藏一般。大词（职场沟通、向上管理）不碰。
2. **不卖"表达力"，卖下游结果**：获客文案禁出现"表达力"三字。卖：晋升答辩不被问倒 / 谈薪多拿的那部分 / 空降老板前30天站稳。教育放交付环节，获客只挂"症状"层。
3. **主输出改图文**：5-7 张图 + 正文 300-500 字。图承载内容、正文承载关键词（自然出现3-5次）。首图=用户搜索原句大字+结论前置（信息型非气质型）。第三张图前必须给出原话。7 图骨架：①原句大字 ②场景还原 ③大多数人答法+为何死 ④我当时的原话 ⑤为什么管用(理论不点名) ⑥可迁移句式 ⑦边界(什么时候没用)。
4. **词库×案例库笛卡尔积**：词库列=关键词/场景类型/意图强度/竞争密度/关联案例ID/状态/发布日/搜索来源占比；案例库列=场景/对方原话/我的原话/结果/可迁移的那一句/已用于哪些笔记。一案例喂7-8词。**指标只盯搜索进入占比**（笔记后台流量来源），不盯播放量。
5. **活人感四要素**：无用的具体细节 / 承认狼狈 / 有代价的观点 / 从对方原话开头。排比句=活人感杀手第一名（全篇最多1处）。抓别人笔记只抓：关键词、标题句式、评论区用户原话、前排答案空缺；**不抓内容本身**。
6. **原话采集系统**：旧记忆从情绪进（哪句让你胃里一沉/事后复述过哪句）；外部检索源（答辩PPT/绩效评语/周报风险栏/邮件/微信吐槽记录）；从今天起"当天三行记录法"（对方原话/我的回应/身体反应）；客户案例是二级供给。真话是短的糙的不完整的，带限定语（"大意是"）反而更可信。
7. **词源扩展到知乎/脉脉**：问题标题天然就是长句搜索词。用 web-access CDP 带登录态采集。

## 图怎么生成（已定方案）

**首选：HTML 模板 + headless Chrome 截图，不用 AI 生图模型。**
- 理由：信息型卡片的本质是排版不是画面；AI 生图对中文大字排版不可靠（错字/字距），HTML 渲染零成本、文字精确、模板可复用可自动化。仓库已有能力：视觉锤封面模板库（commit 1dd3aae）、huashu-design、html-to-pdf skill 的 headless Chrome 渲染。
- 做法：7 图各建一个 HTML 模板（首图大字卡/场景卡/对比卡/原话卡/解释卡/句式卡/边界卡），成稿任务填入文字 → headless Chrome 逐张截图 1242×1660（3:4）。
- 例外：仅当某图确需"画面感"（场景还原插图）时走 Codex CLI 生图（遵守 CLAUDE.md 第十八节，不直接调 OpenAI API）。

## 实施顺序

- **P0 建资产**（先于提示词改造）：
  a. `xhs/素材库/词库.csv`（按上面 8 列建表；现有关键词池 746 词按新标准筛入种子）
  b. `xhs/素材库/案例库.csv`（6 列；从文彬教练实跑案例+腾讯场景清单起步）
  c. `xhs/素材库/图文模板/`：7 个 HTML 模板 + 截图脚本
- **P1 改采集任务提示词**：新增词源（小红书下拉补全/相关搜索/评论区原话/知乎/脉脉问题标题）；竞争密度探测（搜索结果页笔记数+前排赞藏）；不再精读学"内容结构"，改抓"答案空缺"。
- **P2 改成稿任务提示词**：PHASE 1 从词库×案例库选题（不再从热度）；PHASE 2 产图文卡片文字稿+300-500字正文（禁"表达力"、活人感四要素、排比≤1处、第3图前给原话）；PHASE 4 视频降级为可选，图渲染升为主产出。
- **P3 改审核标准**：eric-xhs-audit 增补搜索场景评分维度（搜索意图匹配/首图原句一致性/原话真实颗粒度），必须命中清单同步；晋级线预测(CES/完播)降为推荐流参考项。
- **P4 回流**：发布7天后抓评论区原话补词库；笔记后台"搜索进入占比"回填词库；app 发布数据回流功能与此合并设计。
