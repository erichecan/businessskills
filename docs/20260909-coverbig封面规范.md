# coverbig：图文封面默认样式

2026-09-09 定稿。往后 `xhs/素材库/图文模板/` 出的图文封面（cards.json 第一张卡）默认用这个样式，
不再用纯文字的 `cover` 卡型。

## 长什么样

file:///Volumes/datacenter/04-eric/AIcoding/businessskills/preview/20260909-coverbig-blue.png

- 浅蓝三层渐变网格背景（不深，没有藏青/靛蓝）
- 悬浮白卡：背景渐变在四周露出 64-96px，卡片本身带投影
- 蓝色胶囊标签（圆点 + 文字），替代原来纯文字的 tag
- 大字标题，关键判断词用黄色荧光笔色块高亮（整体换行，不会被自动折行切成两半）
- IP 形象放大居中，身后垫蓝色光晕 + 脚下投影做景深
- 不再放右下角圆形头像签名（`coverbig` 类型不显示 `.foot`）

## 怎么用

`cards.json` 第一张卡：

```json
{"type": "coverbig", "tag": "面试", "title": "面试问能不能<span class=\"hl\">接受加班</span>",
 "quote": "", "body": "他要的不是那句态度<br>是你能待多久的判断", "pose": "pose9_推眼镜反击"}
```

- `pose` **必须按这篇主题的情绪手动挑**，不要留空吃兜底的 `pose1_站立`——42 个姿势里挑一个跟内容气质最搭、且没被这篇其他 6 张卡用掉的。
- 标题要高亮的判断词/结论词用 `<span class="hl">...</span>` 包住，**控制在 3-5 字**（如「接受加班」「他考的不是项目」这类）。这个 span 会整体换行，不会被切开，但也不会自动换行——写太长会整体溢出面板。
- 依然遵守 `make_cards.py` 的版面守恒：文案太长（`est_lines` 超 `LINE_BUDGET`）时姿势图会被自动去掉，报错提示改短文案，不针对 `coverbig` 单独放宽。

渲染方式不变：`python3 make_cards.py 内容.json 输出目录/`。

## 顺带修的一个坑：姿势图透明边距裁剪失效

`trim_poses.py` 和 `split_poses.py` 原来用 `getbbox()` 求内容边界，不带阈值——只要图里有
**一个 alpha=1 的杂点**（羽化留下的噪点），边界就会被撑回整张画布，裁剪等于没生效。

实测 `pose9_推眼镜反击.png`：画布 330×996，裸 `getbbox()` 判定内容铺满全图；加阈值
（alpha > 128）后实际内容只有 330×454。

修法：两个脚本裁边界前都先把 alpha 通道按阈值二值化（`point(lambda a: 255 if a > 128 else 0)`）
再 `getbbox()`。2026-09-09 已用修好的 `trim_poses.py` 重裁了全部 42 张 `pose*.png` 和
`ip.png`，平均放大 1.3~3.3 倍，抽查过没有切到人物本体。这个修复不止影响封面——内文卡
（scene/contrast/why/quote…）用的也是同一批姿势图，人物会跟着一起变大。

原图仍在 `_原图备份/`（更早一版、未去背景的备份），当前这批裁剪结果已提交到 git，出问题可
`git checkout` 回退。
